# 🎓 CollegeGPT – AI-Powered College Helpdesk

CollegeGPT is an AI-powered academic assistant designed to simplify access to college-related information. It enables students to retrieve syllabi, timetables, notices, academic regulations, and other institutional information through natural language conversations.

The application combines modern web technologies with Retrieval-Augmented Generation (RAG) to deliver accurate, context-aware, and document-grounded responses using official college documents.

---

## ✨ Features

- 🤖 AI-powered chatbot for academic queries
- 📚 Retrieval-Augmented Generation (RAG)
- 🔍 Semantic document search
- 📄 Upload and manage academic documents
- 👨‍💼 Secure Admin Dashboard
- 🔐 JWT Authentication
- 💬 Interactive chat interface
- ☁️ Cloud document storage
- 📱 Fully responsive UI

---

## 🚀 System Workflow

### Admin

- Login securely
- Upload syllabus, timetables and notices
- Extract text from uploaded documents
- Generate semantic embeddings
- Store vectors in PostgreSQL
- Save original files to cloud storage

### Student

- Ask questions in natural language
- Convert query into embeddings
- Retrieve relevant document chunks
- Generate AI-powered responses
- Display answers with document references
